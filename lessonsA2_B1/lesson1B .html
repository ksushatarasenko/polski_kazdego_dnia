🧠 2. Главное правило (база)

👉 Мужской род (on)
  • -ak → Polak
  • -ec → Niemiec
  • -anin → Rosjanin, warszawianin
👉 Женский род (ona)

Почти всегда: 👉 добавляется -ka

  • Polak → Polka
  • Niemiec → Niemka
  • Szwed → Szwedka
🔑 Главное правило
  • 👉 С большой буквы — национальности (страны, народы)

    национальности = как «имена народов» → важные → большая буква

  • 👉 С маленькой буквы — жители городов

    жители городов = обычные существительные → маленькая
