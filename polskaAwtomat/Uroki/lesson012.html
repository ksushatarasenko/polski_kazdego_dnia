🎯 Что объединяет эту группу?

Это фундаментальные польские глаголы.

Без них невозможно:

  • говорить о действиях,
  • ходить и передвигаться,
  • просить вещи,
  • описывать повседневную жизнь,
  • строить нормальный разговор.
👉 Главная идея:

автоматическая бытовая речь.

📘 Главное различие глаголов

несовершенный вид → процесс, привычка, повторение

совершенный вид → результат, один завершённый раз

Глагол Главная идея Ощущение
robić / zrobić процесс / результат делать / сделать
iść / chodzić движение сейчас / регулярность иду / хожу
brać / wziąć процесс / взять конкретно, завершённо брать / взять
dawać / dać давать постоянно / дать один раз давать / дать
mieć Тут пары нет. иметь
robić / zrobić = делать / сделать

Один из самых важных глаголов в польском.

🎯 Ощущение:

👉 robić = процесс
👉 zrobić = результат

🧠 Вид глагола

robić → делать
zrobić → сделать

📘 Спряжение — robić

Osoba robić / zrobić (przeszły) robić / zrobić (teraźniejszy) robić / zrobić (przyszły)
ja robiłem/am / zrobiłem/am robię będę robić / zrobię
ty robiłeś/aś / zrobiłeś/aś robisz będziesz robić / zrobisz
on/ona robił/a / zrobił/a robi będzie robić / zrobi
my robiliśmy/aśmy / zrobiliśmy/aśmy robimy będziemy robić / zrobimy
wy robiliście/aście / zrobiliście/aście robicie będziecie robić / zrobicie
oni robili/ały / zrobili/ały robią będą robić / zrobią

Примеры:

  • Что ты делаешь? - Co robisz?
  • Я делаю ужин. - Robię kolację.
  • Я уже это сделал. - Już to zrobiłem.
  • буду готовить. - Będę robić obiad
  • Я делаю кофе каждое утро. - Robię kawę każdego rana.
  • Вчера я приготовил обед. - Wczoraj zrobiłem obiad.
  • Я буду делать задание вечером. - Będę robić zadanie wieczorem.
  • Я сделаю это завтра. - Zrobię to jutro.
  • Она сейчас делает покупки. - Ona robi zakupy teraz.
  • Мы сделали всё быстро. - My zrobiliśmy wszystko szybko.
dawać / dać = давать / дать

Очень полезный глагол для общения.

🎯 Ощущение:

👉 dawać = процесс / регулярно
👉 dać = дать результат

🧠 Вид глагола

dawać → давать
dać → дать

📘 Спряжение — dawać

Osoba dawać / dać (przeszły) dawać / dać (teraźniejszy) dawać / dać (przyszły)
ja dawałem/am / dałem/am daję będę dawać / dam
ty dawałeś/aś / dałeś/aś dajesz będziesz dawać / dasz
on/ona dawał/a / dał/a daje będzie dawać / da
my dawaliśmy/aśmy / daliśmy/aśmy dajemy będziemy dawać / damy
wy dawaliście/aście / daliście/aście dajecie będziecie dawać / dacie
oni dawali/ały / dali/ały dają będą dawać / dadzą

Примеры:

  • Я даю тебе книгу. - Daję ci książkę.
  • Что ты мне даёшь? - Co mi dajesz?
  • Он дал мне деньги. - On dał mi pieniądze.
  • Я буду давать тебе уроки. - Będę dawać ci lekcje.
  • Она часто даёт советы. - Ona często daje rady.
  • Мы дали ему воду. - Daliśmy mu wodę.
  • Я дам тебе ответ завтра. - Dam ci odpowiedź jutro.
  • Они дают детям конфеты. - Oni dają dzieciom cukierki.
  • Ты дашь мне помощь? - Dasz mi pomoc?
  • Мы будем давать подарки. - Będziemy dawać prezenty.
brać / wziąć = брать / взять

Очень частый глагол в разговорной речи.

🎯 Ощущение:

👉 brać = брать / процесс
👉 wziąć = взять результат

🧠 Вид глагола

brać → брать
wziąć → взять

📘 Спряжение — brać

Osoba brać / wziąć (przeszły) brać / wziąć (teraźniejszy) brać / wziąć (przyszły)
ja brałem/am / wziąłem/am biorę będę brać / wezmę
ty brałeś/aś / wziąłeś/aś bierzesz będziesz brać / weźmiesz
on/ona brał/a / wziął/wzięła bierze będzie brać / weźmie
my braliśmy/aśmy / wzięliśmy/aśmy bierzemy będziemy brać / weźmiemy
wy braliście/aście / wzięliście/aście bierzecie będziecie brać / weźmiecie
oni brali/ały / wzięli/ały biorą będą brać / wezmą

Примеры:

  • Я беру кофе. - Biorę kawę.
  • Что ты берёшь? - Co bierzesz?
  • Я взял твой телефон. - Wziąłem twój telefon.
  • Мы будем брать такси. - Będziemy brać taksówkę.
  • Она часто берёт книги. - Ona często bierze książki.
  • Он взял деньги. - On wziął pieniądze.
  • Я возьму это завтра. - Wezmę to jutro.
  • Они берут воду. - Oni biorą wodę.
  • Ты возьмёшь мою книгу? - Weźmiesz moją książkę?
  • Мы быстро всё взяли. - Szybko wszystko wzięliśmy.
mieć = иметь

Один из самых важных глаголов в польском языке.

🎯 Ощущение:

👉 mieć = иметь что-то
👉 używa się bardzo często

🧠 Особенность

mieć не имеет пары вида.
Используется само по себе.

📘 Спряжение — mieć

Osoba mieć (przeszły) mieć (teraźniejszy) mieć (przyszły)
ja miałem/am mam będę miał/a
ty miałeś/aś masz będziesz miał/a
on/ona miał/a ma będzie miał/a
my mieliśmy/aśmy mamy będziemy mieli/ały
wy mieliście/aście macie będziecie mieli/ały
oni mieli/ały mają będą mieli/ały

Примеры:

  • У меня есть машина. - Mam samochód.
  • У тебя есть время? - Masz czas?
  • У неё есть собака. - Ona ma psa.
  • У нас был урок. - Mieliśmy lekcję.
  • Я буду иметь новую работу. - Będę miał nową pracę.
  • Они имеют много денег. - Oni mają dużo pieniędzy.
  • Я имел старый телефон. - Miałem stary telefon.
  • Ты будешь иметь отпуск. - Będziesz miał urlop.
  • Мы имеем хорошую квартиру. - Mamy dobre mieszkanie.
  • Он имел проблему. - On miał problem.
iść / pójść = идти / пойти

Очень важный глагол движения.

🎯 Ощущение:

👉 iść = идти сейчас
👉 pójść = пойти / сходить

🧠 Вид глагола

iść → идти
pójść → пойти

📘 Спряжение — iść

Osoba iść / pójść (przeszły) iść / pójść (teraźniejszy) iść / pójść (przyszły)
ja szedłem/am / poszedłem/am idę będę iść / pójdę
ty szedłeś/aś / poszedłeś/aś idziesz będziesz iść / pójdziesz
on/ona szedł/szła / poszedł/poszła idzie będzie iść / pójdzie
my szliśmy/aśmy / poszliśmy/aśmy idziemy będziemy iść / pójdziemy
wy szliście/aście / poszliście/aście idziecie będziecie iść / pójdziecie
oni szli/ały / poszli/ały idą będą iść / pójdą

Примеры:

  • Я иду домой. - Idę do domu.
  • Куда ты идёшь? - Dokąd idziesz?
  • Он пошёл в магазин. - On poszedł do sklepu.
  • Мы идём в школу. - Idziemy do szkoły.
  • Я пойду завтра. - Pójdę jutro.
  • Они идут сейчас. - Oni idą teraz.
  • Ты пойдёшь со мной? - Pójdziesz ze mną?
  • Мы пошли в парк. - Poszliśmy do parku.
  • Она идёт на работу. - Ona idzie do pracy.
  • Вы пойдёте вечером? - Pójdziecie wieczorem?
chodzić = ходить

Глагол для регулярного движения или движения туда-сюда.

🎯 Ощущение:

👉 chodzić = ходить регулярно
👉 не один раз, а постоянно

🧠 Особенность

chodzić используется для привычек
и повторяющихся действий.

📘 Спряжение — chodzić

Osoba chodzić (przeszły) chodzić (teraźniejszy) chodzić (przyszły)
ja chodziłem/am chodzę będę chodzić
ty chodziłeś/aś chodzisz będziesz chodzić
on/ona chodził/a chodzi będzie chodzić
my chodziliśmy/aśmy chodzimy będziemy chodzić
wy chodziliście/aście chodzicie będziecie chodzić
oni chodzili/ały chodzą będą chodzić

Примеры:

  • Я хожу в школу. - Chodzę do szkoły.
  • Ты часто ходишь в магазин? - Często chodzisz do sklepu?
  • Он ходит пешком. - On chodzi pieszo.
  • Мы ходили в парк. - Chodziliśmy do parku.
  • Я буду ходить на курсы. - Będę chodzić na kursy.
  • Они ходят в кино каждую неделю. - Oni chodzą do kina co tydzień.
  • Ты ходил в эту школу? - Chodziłeś do tej szkoły?
  • Она ходит на работу пешком. - Ona chodzi do pracy pieszo.
  • Мы будем ходить в спортзал. - Będziemy chodzić na siłownię.
  • Вы ходите сюда каждый день? - Chodzicie tutaj codziennie?
